# Модули Okdesk

- `OkdeskApi.psm1`: фиксированный список GET-маршрутов, ключ из окружения, проверка JSON-контракта и потоковое скачивание. API-ключ отправляется только на настроенный HTTPS-сайт Okdesk. Перенаправления API запрещены; скачивание использует отдельный клиент без ключа и cookies. Ссылки на файлы получать непосредственно перед скачиванием.
- Файлы разрешены с сайта аккаунта, `static.okdesk.ru`, `static.okdesk.com`, `okdesk.storage.yandexcloud.net` и явно переданных `TrustedFileHosts`. Каждый адрес, включая перенаправления, проверяется заново. Дополнительные домены не извлекаются автоматически из HTML. При блокировке различать исходную ссылку и перенаправление, недоверенный хост и недопустимые реквизиты; не выводить query или полный URL.
- `OkdeskStorage.psm1`: собственные каталоги data, атомарные файлы, блокировка, разделение сайтов/ключей и срок хранения 30 дней. Не переходить по reparse points. Перед удалением сначала проверить всё принадлежащее клиенту дерево и границы абсолютного пути.
- `OkdeskRead.psm1`: заявка, все возвращённые комментарии, объединение вложений по ID, связанное оборудование, текст/JSON и манифест файлов. Версию iiko не угадывать: агент читает реальные параметры оборудования. Ограничение доступа или несовпадение ID — ошибка.

Вложения больше 500 000 000 байт требуют отдельного разрешения для конкретного ID. Не подменять скачивание картинки текстовым описанием имени. Встроенные изображения и недоступные ссылки отражать в манифесте, не терять молча. Секретные и временные URL не сохранять в манифесте. Не выполнять код при разборе HTML.
