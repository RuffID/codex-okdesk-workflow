# Точка входа клиента

`okdesk.ps1` проверяет сочетание команды и параметров до чтения ключа и сетевых запросов, загружает внутренние модули и выводит один JSON-результат. Ошибки идут в stderr с ненулевым кодом завершения; частично собранные данные не объявляются полным результатом.

`TrustedFileHosts` доступен только при скачивании файлов (`GetIssue -WithAttachments` или `DownloadAttachments`). Это явно подтверждённые дополнительные DNS-имена, а не адреса для отправки API-ключа; не заполнять параметр автоматически из содержимого заявки.

Корень клиента определяется от PSScriptRoot. Не искать другую копию и не использовать AppData как запасной каталог. Нет конфигурации рабочих репозиториев, автозапуска, установки скилла или записи переменных среды. Требуется PowerShell 7.5+.
