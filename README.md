# codex-okdesk-workflow

Локальный PowerShell-клиент и переносимый скилл для чтения Okdesk из [Codex](https://github.com/openai/codex). По номеру заявки клиент собирает описание, комментарии, файлы и карточки прикреплённого оборудования. Скилл объясняет агенту, как прочитать собранные материалы, просмотреть скриншоты и найти версию iiko в учётных данных оборудования.

## Возможности

- Чтение заявки со всеми доступными комментариями и дополнительными полями.
- Скачивание вложений заявки и комментариев с объединением по ID.
- Сохранение встроенных HTML-изображений с доверенных адресов Okdesk и изображений base64, включая PNG в дополнительных полях.
- Чтение прикреплённого оборудования: тип, модель, серийный номер, описание и дополнительные параметры.
- Отдельное чтение оборудования по ID и схемы дополнительных атрибутов оборудования.
- Текстовый контекст, снимок JSON и манифест скачанных и недоступных файлов.

Только чтение: клиент не содержит команд создания, изменения, удаления или списания времени. Произвольные API-запросы не поддерживаются. Рабочие Git-репозитории регистрировать не требуется.

## Требования

- Windows, PowerShell 7.5+ (`pwsh`); дополнительные PowerShell-пакеты не нужны.
- HTTPS-адрес аккаунта вида `https://<account>.okdesk.ru`.
- API-ключ сотрудника с правами просмотра нужных заявок, комментариев, файлов и оборудования. Ключ контактного лица не подходит для оборудования.
- Разрешение на запуск конкретной команды клиента в среде агента.

## Настройка

### Установка через Codex

Сохраните репозиторий в постоянной папке, откройте её в Codex и отправьте промпт ниже.

```text
Установи в мой Codex скилл okdesk-workflow из локальной копии репозитория codex-okdesk-workflow и дай готовые команды PowerShell для подключения к Okdesk.

1. Используй абсолютный путь к корню открытого репозитория. Если он неизвестен, спроси, где находится моя локальная копия.
2. Прочитай Documentation/Technical documentation/setup.md и skills/okdesk-workflow/SKILL.md. Проверь структуру клиента и скопируй папку skills/okdesk-workflow в мой личный каталог скиллов Codex. Если скилл уже установлен, обнови существующую копию. В файле references/local-client.json установленного скилла укажи абсолютный путь к репозиторию клиента в поле clientRepositoryPath, сохранив остальные локальные настройки.
3. Дай один блок PowerShell для ручного запуска. Команды должны запросить HTTPS-адрес аккаунта вида https://<account>.okdesk.ru без дополнительного пути и API-ключ сотрудника. Сохрани их в пользовательские переменные Windows OKDESK_SITE_URL и OKDESK_API_TOKEN. Для ввода ключа используй Read-Host -AsSecureString. Я выполню команды самостоятельно и введу ключ локально. Не проси присылать его в чат.
4. Укажи, где создать API-ключ в настройках аккаунта Okdesk. Для чтения заявок, комментариев, вложений и оборудования используй ключ сотрудника с соответствующими правами.
5. Укажи, куда установлен скилл и какой путь к клиенту сохранён. Напомни, что нужен PowerShell 7.5+ (pwsh) и что после настройки переменных нужно полностью перезапустить Codex. Для проверки предложи отдельный запрос «Посмотри заявку Okdesk <номер> без скачивания вложений». Я подставлю номер реальной заявки, к которой у меня есть доступ.
```

### Ручная установка

1. Сохранить проект в постоянной папке.
2. По [инструкции настройки](Documentation/Technical%20documentation/setup.md) записать адрес и ключ через PowerShell в пользовательские переменные среды Windows. Ключ вводится скрыто и не передаётся в чат или аргументы клиента.
3. Перезапустить Codex, чтобы он получил обновлённое окружение.
4. Когда потребуется подключить скилл, отдельно установить папку `skills/okdesk-workflow`. Наличие копии в этом проекте само по себе скилл в Codex не устанавливает.

Примеры запросов после установки и настройки:

```text
Посмотри заявку Okdesk 12345, прочитай комментарии и просмотри все скриншоты.
Найди версию iiko у сервера, прикреплённого к заявке Okdesk 12345.
Покажи карточку оборудования Okdesk 678.
```

Номера в примерах вымышленные. Версия iiko читается из заполненных полей оборудования; клиент не подключается к серверу и не проверяет фактическую установленную версию.
